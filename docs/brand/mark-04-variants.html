Engawa mark 04, Tatami edges: two variants

Candidate 04 (四畳半の畳縁: four mats around a half mat) in the two variants the site can ship. Both are one path on the same 64 unit grid with the same footprint, 4 units from each side, so the pick changes nothing else on any page. The switch is one line: MARK_VARIANT in components/brand/Mark.tsx, "solid" or "edges", then pnpm brand:icons for app/icon.svg and app/favicon.ico. The build uses solid until then. Written by scripts/brand/variants-page.tsx from the same constants; the page makes no request.
